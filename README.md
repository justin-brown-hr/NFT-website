# Artanova

Premium digital art / NFT collection landing page.

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS
- Framer Motion
- lucide-react
- Google Fonts: Playfair Display, Manrope, Petit Formal Script

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3001](http://localhost:3001).

## Assets

Drop these files into `public/images/`:

| File | Used in |
|------|---------|
| `logo-hummingbird.png` | Nav + Footer |
| `hero-gallery.jpg` | Hero full-bleed background |
| `portrait-about.jpg` | About section portrait |
